# Claudiu

Claudiu is a native desktop app, written in Rust with [GPUI](https://gpui.rs), that runs several [Claude Code](https://code.claude.com) sessions in one window on Windows, macOS and Linux. It is a personal project with rough edges: macOS and Linux are lightly tested, and the macOS build isn't notarized. Issues and pull requests are welcome.

## What it does

Each session is a conversation with Claude Code, Codex, OpenCode or Google Antigravity in Claudiu's own chat view. Claudiu talks to each agent through the [Agent Client Protocol](https://agentclientprotocol.com) (ACP), and sign-in stays with the agent. Settings → Sessions picks the agent for new sessions. Claude Code sessions run through Anthropic's [Claude Agent SDK](https://code.claude.com/docs/en/agent-sdk/overview) with your own `claude`, and need Node and npm. The first one installs the SDK into Claudiu's data folder. Anthropic's [terms](https://code.claude.com/docs/en/legal-and-compliance) don't allow third-party apps built on the Agent SDK to use a Claude Free, Pro, Max or Ultra sign-in without Anthropic's approval, and Anthropic may enforce that without notice. Claudiu uses whatever sign-in your `claude` has, so with a subscription sign-in you use Claude Code sessions in Claudiu at your own risk. An API key, or a cloud provider such as Bedrock or Vertex, is allowed. Codex sessions need Node, because Claudiu runs Codex through its ACP adapter from npm. The chat view takes Claude Code's keyboard shortcuts, such as Esc to interrupt, Esc twice to edit your last message, Shift+Tab to change mode and Up for earlier messages. Continue in a terminal, in a session's actions, ends the session in Claudiu and copies the command that resumes it in a terminal. Pick up a session here, in a project's menu, lists the default agent's sessions in that folder, including ones started in a terminal, and opens the one you choose. Quit it in the terminal first. Hand to another agent starts a session of another agent in the same folder with the conversation so far as its first message. Before each message in a git repository, Claudiu saves the working tree. Review changes, under the message box, then shows what changed since your last message, hunk by hunk. Each hunk can be kept or reverted. A comment on a line goes back to the agent as `@path#L12: comment`. Around the chat, Claudiu adds a sidebar of running and recent sessions (Ctrl+Z, or Cmd+Z on macOS, reopens the last one you closed), notifications when a background session finishes or asks something, an editor mode (Ctrl+Shift+E), usage meters, a GitHub pane, cards Claude draws inline, sessions that move between git worktrees, extra accounts that share one configuration, and Codex, OpenCode and Google Antigravity subagents (Settings → Custom subagents). Codex subagents need Node and a `codex login`, OpenCode subagents need `opencode` on PATH, Antigravity subagents need the Antigravity CLI (`agy`) installed and signed in, and with Allow edits on, each acts without Claude Code's permission rules. Read-only Antigravity runs from its own folder in Claudiu's data, whose hook refuses every tool but reading and searching, so your own Antigravity rules, skills and MCP servers don't load there. Google's [Antigravity terms](https://antigravity.google/terms) and [FAQ](https://antigravity.google/docs/faq) forbid using another company's agent, such as Claude Code, with a personal Google sign-in. That covers the Free, AI Plus, Pro and Ultra plans. Google can suspend or terminate the Antigravity and Gemini CLI accounts of anyone who does, so turn Antigravity subagents on at your own risk. With Codex subagents on, the sidebar also shows Codex's 5-hour and 7-day limits, which Claudiu reads from the session logs in `~/.codex`; with Antigravity subagents on, it shows Antigravity's limits for each group of models, from `agy`'s own `/usage`, asked every five minutes at no token cost. Their last saved readings show at launch and refresh in the background. Settings lists the rest.

While a custom subagent works, its own view in Claude Code's tasks list streams its messages, reasoning, plan and tool steps and command output. The main conversation stays as it is until the subagent hands back its report. The first Codex run takes longer while npm downloads the adapter. Claude can choose a Codex subagent's effort when it starts one (`max` runs as Codex's `xhigh`); otherwise Codex uses the effort in `~/.codex/config.toml`.

A message Claude sends a running Codex subagent reaches it in the task it is working on, and its answer streams like the rest. OpenCode takes such messages too if its version supports them. Antigravity and older OpenCode versions get the message as a follow-up once the current turn ends, as does a subagent that has already finished. Antigravity takes the effort Claude asks for, capped at the highest thinking level its model offers.

## What it touches

Claudiu never calls the Anthropic API or deletes a transcript, and it changes Claude Code's settings only when you flip a switch. In a git repository, each session keeps its 20 newest working-tree snapshots as commits under `refs/claudiu/`. They never touch your index, branches or stash, but `git log --all` shows them. Its network use is GitHub (the update check and the GitHub pane), npm for the Claude Agent SDK and the Codex adapter, OpenAI once you use Codex sessions or turn on Codex subagents, the providers you set up in OpenCode once you turn on OpenCode subagents, and Google once you turn on Antigravity subagents. Terminal contents are never logged.

## Development

You need stable Rust, plus Visual Studio Build Tools on Windows or the headers GPUI builds against on Linux, and [just](https://just.systems): `just run`, `just test`, `just ci`. `src/` is the app, `vendor/gpui-base/` is a patched copy of the editor crate (`Cargo.toml` says what the patch changes and when to drop it), `mod/` is the Claude Code plugin each session loads, `bridge/` is the Node script that runs Claude Code sessions through the Claude Agent SDK (its lockfile pins the SDK), and `web/` is the site. `CLAUDE.md` has the conventions. A debug build keeps its data in its own folder, so it runs beside the installed app; a second app on the same folder says Claudiu is already running and quits. To release, bump `version` in `Cargo.toml` and push a `vX.Y.Z` tag.
